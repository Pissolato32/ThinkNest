# ThinkNest Settings Screen Specification (`SCR_006_SETTINGS`)

**Version:** 1.0  
**Status:** Approved  
**Screen Component:** Settings & Configuration

---

## 1. Configurable Modules

- **AI Provider Management:** Configure default provider (OpenAI, Anthropic, Gemini, Local Ollama/CoreML), enter custom API keys, and test latency.
- **Data & Storage:** Export entire SQLite database, trigger cloud sync, clear local cache, manage storage footprint.
- **Biometric Security:** Enable Face ID / Touch ID / Fingerprint lock for opening ThinkNest.
- **Appearance & Theme:** System preference default, Dark Mode override, font scaling options.
