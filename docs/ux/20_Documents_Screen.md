# ThinkNest Documents Screen Specification (`SCR_004_DOC_VIEWER`)

**Version:** 1.0  
**Status:** Approved  
**Screen Component:** Document List & Fullscreen Markdown Viewer

---

## 1. Features & Capabilities

- **Multi-Document Management:** Tabs or list view for generated PRDs, System Architectures, Roadmaps, and Outlines.
- **Render Modes:** Toggle between rendered Markdown view (formatted tables, Mermaid diagrams, bold headings) and raw Markdown code editor.
- **Export Actions:** Quick share via native share sheet (PDF, Markdown file, Copy to Clipboard, Export to Notion).
