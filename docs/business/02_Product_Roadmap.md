# ThinkNest Product Roadmap (v1.0 -> v2.0)

**Version:** 1.1  
**Status:** Approved  
**Lifecycle:** Feature Trajectory

---

## 1. Release Horizons

- **Phase 1 (v1.0 - Android & Web Launch):**
  - Flutter (Dart) app targeting Android and Web.
  - Instant Quick Capture using local on-device Speech-to-Text (`speech_to_text`) with cloud Whisper refinement when online.
  - Supabase backend integration (PostgreSQL, Supabase Auth, Storage, Edge Functions).
  - Grill-me Incubation Engine & Document Generator (requires network connection).
  - Full local editing & project management when offline.
  - Implementation Pack export (.zip).
- **Phase 2 (v2.0 - iOS & Offline AI Execution):**
  - Native iOS support using the unified Flutter codebase.
  - Local SLM integration using **ExecuTorch** for offline AI incubation sessions.
  - Advanced 1-click sync to Notion, Linear, GitHub, and Cursor.
  - Third-party Extension SDK & Plugin Store.
