# UX Principles

- Home always opens on Quick Capture.
- Never require project type selection during capture.
- Maximum one blocking question after capture.
- AI should infer rather than ask.
- Every interaction must create visible value.
- Use progressive disclosure.
- Dark theme is the primary design target.
- FAB (+) is always visible on project listing.
- Empty states inspire, never intimidate.
- Users must always know the next recommended action.
